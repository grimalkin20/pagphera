# Pagphera

Premium, editorial wedding photography and cinematography website. This repository is currently in **Phase 0: discovery and planning**. No frontend implementation has started.

## Current status

- Phase 0 brief and architecture: complete.
- Phase 1 design system and frontend foundation: in progress.
- Backend, admin, analytics, and deployment: intentionally deferred.

## Technology direction

The approved implementation direction is semantic HTML5, CSS3, and vanilla JavaScript for the frontend, with PHP and MySQL/MariaDB reserved for a later backend phase. No frontend framework or CSS framework is planned.

## Content boundary

All names, locations, testimonials, contact details, social links, images, videos, prices, awards, and legal/business details remain placeholders until the studio authorizes real content. Demo testimonials, if ever used, will be visibly labeled as demo content.

## Next checkpoint

Phase 1 now contains the shared design foundation and a small, non-production preview page. Its navigation links only to implemented on-page sections, and its disabled inquiry controls explicitly do not collect data. The remaining Phase 1 browser checks are in `docs/testing-checklist.md`.
